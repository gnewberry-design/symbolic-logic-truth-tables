✨ M — MODEL (I DO)

Let p and q represent statements that are each either T (true) or F (false).

🟢 AND (p ∧ q): True only if both statements are true.
🔵 OR (p ∨ q): True if at least one statement is true, including both.
👻 NOT (¬p): Flips the truth value of p.

🎃 Example 1: ¬(p ∧ q)

Given p = F and q = F:

Step 1️⃣ Inside parentheses: F ∧ F = F.

Step 2️⃣ Apply NOT: ¬F = T.

✅ Final answer: TRUE

🦇 Example 2: ¬(p ∨ q)

Given p = T and q = F:

Step 1️⃣ T ∨ F = T.

Step 2️⃣ ¬T = F.

✅ Final answer: FALSE

🔮 Example 3: (¬p) ∧ q

Given p = F and q = T:

Step 1️⃣ ¬p = T.

Step 2️⃣ T ∧ T = T.

✅ Final answer: TRUE

🧙 Example 4: p ∨ (¬q)

Given p = F and q = T:

Step 1️⃣ ¬q = F.

Step 2️⃣ F ∨ F = F.

✅ Final answer: FALSE

🔍 A — ANALYZE

Compare these two expressions. The NOT symbol changes what is being negated:

👻 ¬(p ∧ q) means “NOT [p AND q].”

🎃 (¬p) ∧ q means “[NOT p] AND q.”

Important: These expressions do not always have the same truth value.

💡 De Morgan's Laws (extension): ¬(p ∧ q) is equivalent to (¬p) ∨ (¬q); ¬(p ∨ q) is equivalent to (¬p) ∧ (¬q).
